# AstatVPN: приложение

Клиент VPN на ядре Xray для Android, Windows, iOS, macOS и Linux. Один код на Flutter, VPN-часть у каждой системы своя.

## Чем отличается от Happ, v2rayNG и похожих

- Нет локального SOCKS/HTTP-прокси и портов управления ядром. Трафик идёт из системного VPN прямо во вход `tun` Xray, поэтому другие программы на устройстве не могут через localhost узнать выходной адрес, достать ключи или обойти раздельное туннелирование.
- Готовые конфигурации из подписки (в них обычно прописан открытый SOCKS на 10808) перед запуском переносятся на `tun`, лишние входы и API вырезаются (`lib/core/xray_config.dart`).
- DNS-запросы приложений перехватываются и идут через туннель. IPv6 на Android не настраивается намеренно: система блокирует его целиком, и он не уходит мимо VPN.
- Проверка сертификата не отключается: ссылки с `insecure=1` без отпечатка отклоняются с объяснением.
- Идентификатор устройства для подписки случайный, с железом не связан.
- Резервное копирование данных приложения в облако отключено: ключи подписок и токен аккаунта не покидают устройство.

## Сборка

```bash
tool/build_core_android.sh   # ядро Xray (libXray.aar) и геобазы, нужны Go, JDK 17, Android SDK и NDK
flutter build apk --release
```

Windows (служба кросс-компилируется на любой системе, само приложение и установщик собираются только в Windows):

```bash
tool/build_core_windows.sh                       # служба astat-helper.exe с ядром Xray, wintun.dll, геобазы
flutter build windows --release
iscc windows\installer\astatvpn.iss             # установщик, нужен Inno Setup 6.3+
```

macOS (нужен Mac с Xcode, аккаунт разработчика Apple не нужен):

```bash
tool/build_core_macos.sh                         # служба astat-helper с ядром Xray и геобазы
flutter build macos --release
tool/package_macos.sh                            # build/installer/AstatVPN.dmg
```

На macOS, как и на Windows, приложение работает без прав администратора, а туннель поднимает служба (`core/`, Go). Служба лежит внутри приложения; по кнопке «Установить службу» она копируется в `/Library/Application Support/AstatVPN` и запускается через launchd, система при этом спрашивает пароль администратора. Приложение говорит со службой через сокет `/var/run/astatvpn.sock`; служба отвечает только тому, кто вошёл в систему за этим Mac. На время подключения служба направляет системный DNS в туннель и возвращает его при отключении и после сбоя. Приложение подписано без сертификата Apple, поэтому при первом запуске macOS предупреждает о неизвестном разработчике.

iOS (нужен Mac с Xcode):

```bash
tool/build_core_apple.sh                         # ядро Xray (LibXray.xcframework) и геобазы
flutter build ios --simulator --debug            # проверка сборки без подписи
flutter build ipa --release                      # для устройств и App Store: нужна платная программа Apple Developer
```

На iOS туннель поднимает расширение системного VPN (цель `Tunnel` в `ios/Runner.xcodeproj`, код в `apple/`). Ядро читает пакеты прямо из интерфейса туннеля, который создаёт система, как на Android. Расширению нужны права Network Extension, которые Apple выдаёт только участникам платной программы; в симуляторе системный VPN недоступен, там проверяется всё, кроме самого туннеля.

На Windows приложение работает без прав администратора. Туннель поднимает служба `AstatVPNHelper` (`core/`, Go), которую ставит установщик; приложение говорит с ней через именованный канал `\\.\pipe\AstatVPN`. Служба принимает только конфигурацию с единственным входом `tun` и отклоняет всё, что ссылается на файлы или программы (`core/internal/sanitize`).

Ядро и геобазы в git не хранятся. Проверка: `flutter analyze` и `flutter test`.

### Подпись APK

Постоянный ключ лежит вне репозитория. Сборка ищет файл `key.properties` (поля `storeFile`, `storePassword`, `keyAlias`, `keyPassword`; путь к хранилищу считается от каталога этого файла) по очереди: переменная `ASTAT_KEY_PROPERTIES`, `android/key.properties`, `~/.astatvpn/key.properties`. Если файла нет, APK подписывается отладочным ключом и не обновит приложение, установленное с постоянным.

Ключ нельзя потерять: без него обновления перестанут ставиться поверх установленного приложения. Копию `~/.astatvpn/` нужно хранить отдельно от компьютера.

### Журнал

Настройки → Журнал показывает сообщения ядра. Переключатель «Подробный журнал» записывает ход каждого соединения (с адресами сайтов), он нужен для разбора сбоя: на обычном уровне неудачное подключение к серверу в журнал не попадает.

## Устройство

| Что | Где |
|---|---|
| Разбор ссылок серверов | `lib/core/share_link.dart` |
| Подписки | `lib/core/subscription.dart` |
| Сборка конфигурации Xray | `lib/core/xray_config.dart` |
| Состояние приложения, аккаунт ASTAT | `lib/core/app_state.dart`, `astat_api.dart` |
| Связь с VPN-службой | `lib/core/vpn.dart` (канал `astat/vpn`) |
| Экраны | `lib/ui/` |
| Значок приложения | `tool/make_icons.py` (рисует и раскладывает по всем системам) |
| VPN-служба Android | `android/app/src/main/kotlin/shop/autohitech/astatvpn/` |
| Расширение VPN для iOS | `apple/` (Swift), цель `Tunnel` в `ios/` |
| Служба Windows и macOS | `core/` (Go), связь из приложения: `lib/core/vpn_desktop.dart` |
| Установщик Windows | `windows/installer/astatvpn.iss` |
